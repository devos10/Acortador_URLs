# 🚀 Acortador de URLs

Un proyecto para acortar enlaces largos en URLs cortas y fáciles de compartir.  

## 📌 Estado del proyecto
**Estatus:** 🚧 En proceso  

Este proyecto aún está en desarrollo activo. Las funcionalidades pueden cambiar y no se recomienda para producción por ahora.

## 📖 Descripción
La idea es crear un sistema que:
- Reciba una URL larga como entrada.
- Genere un enlace corto único.
- Permita redirigir a la URL original al acceder al enlace corto.

## 🛠️ Tecnologías (planeadas)
- Backend: (PHP)
- Base de datos: (MySQL)
- Frontend: HTML, CSS, JavaScript
